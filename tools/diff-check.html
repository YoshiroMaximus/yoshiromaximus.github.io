Diff Finder

Compare two pieces of text and see exactly what changed. Diffs are computed in your browser — nothing leaves your device.

Keyboard shortcuts

⌘/Ctrl + Enter
Recompute diff now
⌘/Ctrl + ⇧ + S
Swap A and B
⌘/Ctrl + ⇧ + L
Clear both panes
⌘/Ctrl + ⇧ + D
Toggle dark theme
⌘/Ctrl + ⇧ + U
Toggle unified / side-by-side
?
Show this dialog
Esc
Close menus and dialogs

Tips

Drag & drop a file onto either pane to load it. Use Options → Ignore whitespace to compare code that has been reformatted. Use Copy shareable link to send your diff to someone else — the entire diff is encoded in the URL.
