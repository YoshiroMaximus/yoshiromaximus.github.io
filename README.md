Personal site, hand-written HTML with no framework and no build step. Every page is self-contained: inline CSS, inline JS, no shared files.

> **This is the `oreui` branch.** It powers [yoshiromaximus.github.io](https://yoshiromaximus.github.io) via GitHub Pages, with `portfolio.html` (the Minecraft-style **Ore UI** portfolio) as the centerpiece. The `2026` branch is the main line, deployed to [sn4k.org](https://sn4k.org) on Cloudflare Workers.
